# 國科會計畫一頁式（草案）

## 計畫名稱
medippi 划船運動表現分析系統：手機即時影像姿態辨識結合穿戴裝置（BLE/ANT+）生理與表現數據之多模態分析與訓練處方生成

## 一、研究目的
本計畫建置可於訓練現場即時運作之划船運動表現分析系統，以手機/攝影機即時擷取影像並進行姿態骨架辨識，萃取關節角度、動作分期與姿勢穩定性指標；同步整合穿戴裝置（Garmin 心率帶/運動手錶）透過 BLE 與 ANT+ 傳輸之心率與運動表現資料（功率、划頻、里程等），於大螢幕即時回饋技術與生理狀態，建立可解釋之指標體系與訓練處方建議流程，以支援爆發力、耐力與技術動作提升，並作為個人化訓練處方訂製與長期追蹤之基礎。

## 二、研究方法
(1) 影像姿態分析：採 MediaPipe Pose 進行即時骨架追蹤，計算膝/髖/肘等關節角度與 ROM，並以平滑與異常值抑制提升角度序列穩定性。  
(2) 動作分期：建立划船分期（Catch/Drive/Finish/Recovery）之規則化/狀態機判別，輸出分期特徵與技術品質指標（穩定性、流暢度、一致性）。  
(3) 穿戴整合：以 BLE（Heart Rate Service）與 ANT+（HR profile + USB dongle）雙通道擷取心率，設計多來源融合策略（資料新鮮度/連線品質/優先序）。  
(4) 多模態同步與即時回饋：以 timestamp 為核心對齊影像與感測資料，透過 WebSocket 推送儀表板；採原始事件（JSONL）＋分析資料（Parquet）雙層儲存。  
(5) 訓練處方：先以可解釋規則（指標閾值/模板差距）提供技術修正與訓練建議；後續以統計驗證建立指標與表現關聯，再逐步發展預測模型支援個人化處方。

## 三、可行性
本計畫採成熟可部署之電腦視覺與姿態辨識工具鏈（OpenCV/MediaPipe/Python），並以標準通訊協定（BLE/ANT+）介接穿戴裝置；以模組化架構（影像分析、感測整合、資料融合、即時顯示、資料儲存與報表）降低研發風險，先完成 MVP 達成現場即時回饋，再迭代強化分期穩健性、資料庫與處方功能，確保階段性交付。

## 四、預期成果
(1) 可部署即時系統原型：完成影像姿態＋穿戴數據整合之即時分析平台，支援大螢幕儀表板與 session 記錄/匯出。  
(2) 指標體系與資料字典：建立角度、ROM、分期特徵、穩定性及生理/表現指標之定義與計算流程。  
(3) 驗證報告與可解釋回饋規則：完成延遲、分期一致性、同步誤差等性能驗證，並形成教練可採用之技術回饋。  
(4) 擴充基礎：具備雲端化與多感測器整合之架構基礎，支援長期追蹤與模型化處方。

## 五、關鍵績效指標（KPI）
(A) 即時性：端到端延遲（影像→分析→儀表板顯示）建議 ≤ 300 ms（依硬體驗收）。  
(B) 分析正確性：分期與人工標註一致性（accuracy/F1 或轉換點誤差）；角度/ROM 重測一致性。  
(C) 數據整合：BLE + ANT+ 心率雙來源擷取成功率與連續性；多模態同步誤差建議 ≤ 0.5–1.0 s（依取樣率驗收）。  
(D) 可用性：儀表板可讀性與教練採用度（量表/訪談）；回饋可解釋性（每項建議可回指角度/分期/穩定性指標）。
